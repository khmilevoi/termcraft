Row states during a turn the kernel matrix is per-command, not a block

A running turn refuses four capabilities — /new, /chats, /export, /model. Everything else stays live: the whole /commit-* family per Git scope, cancel, and /exit, which carries no kernel capability at all and must never dim — a stuck turn is exactly when it gets used. The single blanket dim no longer holds, so the row treatment splits in two:

/export  locked · turn running

Locked — comes back. The command name holds at muted, not faint, and its description is swapped for the reason in amber-dim — the same amber that means “in progress” everywhere else in the system. Readable, and visibly temporary.

/commit-infra  nothing to commit

Unavailable — nothing to do. Name and reason both drop to faint with no amber anywhere. Waiting will not change it; the scope is simply clean. The absent ● dot already says so — the reason line makes it explicit.

● /commit-all  entire project · 7 files

Available. Unchanged. Selection still lands on the first available row, so the highlight is never parked on something Enter will refuse.

Anchored to the Home prompt one or two rows · or none at all

The Home prompt is a primary input, so / opens the menu there too — the · / model hint beside the selectors has been promising it all along. It cannot hang above the box the way the composer's does; the logo and tagline sit there. It drops below the box instead, left edge aligned, in the row the removed ready-health line just vacated (§01). It is also narrower than the box: two rows in an 84-column frame would read as a mistake, so the menu takes its own 42 columns and the prompt keeps its width.

Home's applicable set is small — commands meaningless here are hidden rather than dimmed, so five of the eight rows never appear. /model shows dimmed against its own availability predicate (the picker is v1.0), which leaves /exit as the one row Enter can actually run. And when a filter matches nothing, the menu does not open and does not warn: the characters stay in the prompt as ordinary text and Enter still creates the project with them. Silence is the design — a “no commands” panel would be louder than the thing it reports.
