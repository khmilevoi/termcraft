One .termcraft folder holds exactly one project, so Home is only ever shown before a project exists — an existing project opens straight into the Workspace. It is the large centered prompt, the inline agent · model · effort selectors, and the status bar. No project list, no empty/populated split.

The green ● codex 0.34 · agent ready line is removed. The agent is already named by the combo row one line above it, a genuinely missing CLI still takes over the whole screen (§12), and its only unique job — asserting ready — is the one claim that cannot be made while the health probe is still running. The prompt stack now centres on itself, and the row the line used to occupy is where the Home slash menu opens (§23).

Health check in flight input live · submit refused · reason legible

Identity, model and effort are known with no I/O, so they paint on the first frame. Health is not: the probe spawns the CLI and is bounded at 20 s. Through that window the prompt is fully live — amber ❯, real text, blinking caret — and only ⏎ is refused, exactly the split the composer already uses during a turn. Two things carry the refusal: the ⏎ create affordance goes faint with the reason beside it, and the status bar takes a ⠹ checking badge while its ⏎ create key renders faint instead of amber. A faint key in the status bar is the system's new word for “this gesture is refused right now” — §03 uses the same one.

Resolution is a state change, not a layout change: the badge drops out, the key turns amber, the hint returns to plain ⏎ create. Nothing moves, nothing is added — which is only possible because the ready line is gone. If the probe fails, Home either takes on an inline notice (below) or is replaced entirely (§12).

The other health outcomes probe finished · agent not simply “ready”

The probe reports five outcomes. Ready is now silent, and a missing CLI keeps its full-screen takeover in §12. The remaining three attach a notice under the prompt box instead of replacing the screen — a failure has earned a line on Home in a way a success has not. Only not signed in blocks: the prompt greys out and ⏎ stays faint, because a turn would be billed against a CLI that cannot answer. The other two are advisory — ⏎ works — and say plainly what is unproven. The 20 s timeout in the checking state resolves here, to not signed in.
