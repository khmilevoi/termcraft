❯ termcraft design system · terminal UI

Describe a TUI in chat, a local agent generates it, and it renders live in the terminal. Below: the tool itself — one dark theme, one amber accent, ratatui-style widgets on a strict character grid. Everything is real monospace cells (JetBrains Mono), box-drawing chrome, no pixel geometry.
